# Cron Studio — конструктор cron-выражений

Настольное приложение в стиле Windows 11 для визуального создания, разбора и отладки
cron-выражений в формате **Quartz (7 полей)** — с имитацией полноценного рабочего стола:
окна, панель задач, обои, калькулятор и параметры персонализации.

Приложение реализовано как веб-проект (React + Vite) и без переделки интерфейса может быть
упаковано в настоящий `.exe` для Windows через Tauri или Electron (см. раздел ниже).

## Основные возможности

- Полная поддержка **7-полевого формата Quartz**: `сек мин час день-месяца месяц день-недели год`,
  например `0 00 11 ? * * *` (ежедневно в 11:00:00 — подставлен примером по умолчанию).
- Автоматический разбор выражений из **5, 6 и 7 полей** (классический cron, Quartz без года,
  полный Quartz) с приведением к 7 полям.
- Визуальный конструктор каждого поля без знания синтаксиса.
- Расшифровка выражения на человеческом русском языке.
- Расчёт 8 ближайших срабатываний с относительным временем («через 2 часа 30 минут»).
- Копирование/вставка через буфер обмена одной кнопкой.
- Экспорт в трёх форматах: 7 полей, 6 полей, 5 полей (классический).
- Валидация с понятными ошибками и предупреждениями на русском.
- 15 готовых шаблонов и встроенная справка по спецсимволам.
- Рабочий стол в стиле Windows 11: окна, панель задач, обои, часы, значки.

## Конструктор cron-выражений

Каждое из семи полей настраивается в отдельной карточке с выбором режима:

| Поле          | Режимы                                                                                          |
|---------------|--------------------------------------------------------------------------------------------------|
| Секунды       | все (`*`), интервал (`x/n`), список (`0,15,30`), диапазон (`a-b`), диапазон с шагом, свой текст |
| Минуты        | аналогично                                                                                        |
| Часы          | аналогично                                                                                        |
| День месяца   | не задано (`?`), каждый день, по числам, интервал, диапазон, последний день (`L`), за N дней до конца (`L-N`), последний будний (`LW`), ближайший будний к числу (`NW`) |
| Месяц         | все, по месяцам (Янв–Дек), интервал, диапазон, свой текст                                         |
| День недели   | не задано (`?`), каждый день, по дням (Пн–Вс), диапазон (`MON-FRI`), N-й день месяца (`FRI#2`), последний такой день (`FRIL`) |
| Год           | любой, конкретные годы, диапазон, интервал, свой текст                                            |

Дополнительно:

- **Панель выражения** — поле ввода с разметкой семи полей разными цветами, применение
  по Enter, кнопки «Вставить», «Копировать», «Сброс».
- **Человеческим языком** — итоговое описание («По будням в 09:00:00», «Каждую вторую
  пятницу месяца в 14:30:00») плюс построчный разбор каждого поля.
- **Ближайшие запуски** — восемь следующих срабатываний; корректно обрабатываются
  `L`, `LW`, `nW`, `x#n`, `xL`, шаги и диапазоны, переходы через дни/месяцы/годы.
- **Экспорт** — 7 полей (Quartz), 6 полей (без года), 5 полей (классический cron с
  пересчётом дня недели `1=Вс` → `0=Вс`).
- **Проверка** — ошибки диапазонов, обратные диапазоны, шаг `< 1`, а также предупреждение,
  когда одновременно ограничены «день месяца» и «день недели» (Quartz рекомендует `?`
  в одном из них).
- **Шаблоны** — «Каждые 5 минут», «По будням в 9:00», «Последний день месяца»,
  «Последний будень месяца», «Каждую 2-ю пятницу» и др. Применяются одним щелчком.
- **Справка** — таблица всех спецсимволов (`* ? , - / L L-n W LW # C`), порядок полей,
  допустимые значения и примеры, применяемые кликом. Открывается кнопкой в заголовке окна,
  закрывается по Esc.

## Рабочий стол Windows

Экран имитирует рабочий стол Windows 11:

- **Окно приложения** — заголовок с иконкой, кнопки «Свернуть / Развернуть / Закрыть».
  Разворачивается на весь экран под любое разрешение, в режиме окна перетаскивается
  за заголовок (двойной щелчок — развернуть/восстановить). Закрытие показывает рабочий
  стол с предложением запустить приложение снова.
- **Панель задач** — кнопка «Пуск», закреплённые приложения с индикаторами запуска
  (Cron Studio, Проводник, Калькулятор, Параметры), системный трей и живые часы с датой.
  Свёрнутое приложение восстанавливается щелчком по значку.
- **Значки рабочего стола** — «Cron Studio», «Калькулятор», «Корзина»; запуск двойным
  щелчком, выделение одиночным.
- **Обои** — четыре варианта + пользовательская картинка, смена с плавным переливом.

## Калькулятор

Отдельное плавающее окно (перетаскивание, вывод на передний план кликом, закрытие):

- **Стандартный режим** — цифры, `+ − × ÷`, `%`, `1/x`, `x²`, `√x`, `±`, CE, C, стереть.
- **Расширенный режим** — скобки `( )`, степень `xʸ`, факториал `n!`, `sin / cos / tan`
  (переключатель градусы/радианы DEG·RAD), `ln`, `log`, `π`, `e`, `|x|`.
- Живое превью результата прямо во время ввода, строка истории последнего вычисления.
- Полная работа с клавиатуры: цифры, операторы, `Enter` — вычислить, `Backspace` — стереть,
  `Esc` — сброс.
- Ошибки на русском: «Деление на ноль», «√ из отрицательного», «Не хватает закрывающей
  скобки» и т.д.
- Вычислитель — собственный безопасный парсер (алгоритм «сортирующая станция» /
  shunting yard), без `eval`; корректно считает приоритеты, унарный минус и `0.1 + 0.2 = 0.3`.
- Выбранный режим и DEG/RAD запоминаются между запусками.

## Параметры и персонализация

Окно «Параметры» (иконка шестерёнки в панели задач) → раздел «Персонализация → Фон»:

- **4 встроенных обоя** с миниатюрами: «Сапфир», «Рассвет», «Аврора», «Закат».
- **Своя картинка** — загрузка любого изображения; файл автоматически уменьшается до
  1920 px по ширине (JPEG, качество 85%) и сохраняется в браузере.
- Выбор обоев **запоминается между запусками**; при переполнении хранилища показывается
  предупреждение с советом выбрать файл поменьше.
- Кнопка «Вернуть обои по умолчанию».

## Формат cron (Quartz)

Порядок полей и допустимые значения:

```
┌─────────┬─────────┬──────┬─────────────┬────────┬─────────────┬────────────┐
│ Секунды │ Минуты  │ Часы │ День месяца │ Месяц  │ День недели │ Год        │
│ 0–59    │ 0–59    │ 0–23 │ 1–31        │ 1–12   │ Пн–Вс       │ 1970–2099  │
│ ,-*/    │ ,-*/    │ ,-*/ │ ,-*?/LWC    │ ,-*/   │ ,-*?/L#C    │ ,-*/       │
└─────────┴─────────┴──────┴─────────────┴────────┴─────────────┴────────────┘
```

| Символ | Значение                                                        | Пример                          |
|--------|-----------------------------------------------------------------|---------------------------------|
| `*`    | любое значение                                                  | `*` в минутах — каждую минуту   |
| `?`    | «не задано» (только день месяца / день недели)                  | `0 0 12 ? * MON`                |
| `,`    | список                                                          | `MON,WED,FRI`                   |
| `-`    | диапазон                                                        | `9-18`, `MON-FRI`               |
| `/`    | шаг                                                             | `0/15` — каждые 15, начиная с 0 |
| `L`    | последний день месяца / последний такой день недели             | `L`, `6L` (последняя пятница)   |
| `L-n`  | за n дней до конца месяца                                       | `L-3`                           |
| `W`    | ближайший будний день к дате                                    | `15W`                           |
| `LW`   | последний будний день месяца                                    | `0 0 18 LW * ?`                 |
| `#`    | N-й день недели в месяце                                        | `FRI#2` — вторая пятница        |

Нумерация дней недели Quartz: `1=Вс, 2=Пн … 7=Сб` (в конструкторе используются имена
MON–SUN, поэтому неоднозначности нет). При импорте 5-полевого классического выражения
нумерация автоматически пересчитывается (`0=Вс` → `1=Вс`).

## Технологический стек

| Инструмент       | Назначение                                              |
|------------------|---------------------------------------------------------|
| React 19         | интерфейс                                               |
| TypeScript (strict) | типизация всей логики                                |
| Vite 7           | сборка, dev-сервер                                      |
| Tailwind CSS 4   | стилизация (тёмная Fluent-тема Windows 11)              |
| framer-motion 12 | анимации окон, тостов, смена обоев                      |
| lucide-react     | иконки интерфейса                                       |
| vite-plugin-singlefile | упаковка assembly в один HTML-файл (`dist/index.html`) |

Вся cron-логика (парсинг, сборка, валидация, расчёт запусков, описания) и вычислитель
калькулятора написаны без внешних зависимостей и покрыты юнит-тестами логики.

## Запуск и сборка

```bash
# установка зависимостей
npm install

# режим разработки (http://localhost:5173)
npm run dev

# production-сборка → dist/index.html (один самодостаточный файл)
npm run build
```

После сборки достаточно открыть `dist/index.html` — все скрипты и стили уже встроены;
обои лежат рядом в `dist/`.

## Упаковка в десктопное приложение Windows

Интерфейс изначально спроектирован под десктоп (адаптация под разрешение, поведение окон),
поэтому для получения настоящего `.exe` проект достаточно обернуть:

**Вариант 1 — Tauri (рекомендуется, ~3–10 МБ):**

```bash
npm install -D @tauri-apps/cli
npx tauri init          # указать dist/ как frontendDist
npx tauri build         # получите .msi/.exe в src-tauri/target/release
```

**Вариант 2 — Electron:**

```bash
npm install -D electron electron-builder
# main.js: создать BrowserWindow и загрузить dist/index.html
npx electron-builder --win
```

## Хранение данных

Приложение хранит настройки локально в браузере (localStorage):

| Ключ                    | Содержимое                                             |
|-------------------------|--------------------------------------------------------|
| `cronstudio.wallpaper`  | выбранные обои и dataURL пользовательской картинки     |
| `cronstudio.calc`       | режим калькулятора (стандартный/расширенный), DEG/RAD  |

Никакие данные не покидают устройство — вычисления cron и калькулятора выполняются
полностью на клиенте.
